3. Exemplos com comentários no trade off 
    - Consumo de memória x velocidade:
        Ex: Ao usar um linguagem mais próxima da máquina para a projeção de uma aplicação, aumenta-se a performance, porém diminui a portabilidade do código para os vários modelos de dispositivo devivdo a uma generalização do código que impede o aproveitamento total de cada máquina
    - Performance x consumo de energia:
        Ex: Praticar o uso overclock permite um ganho em velocidade de processamento porém com isso tem-se um aumento no consumo de energia que pode comprometer o fuincionamento de outras partes da máquina.
    -  Segurança x Praticidade:
        Ex: O uso de mais etapas de segurança que por um lado dificultam a invasão do sistema, faz com que o aumento das camadaspor sua vez diminuam a usabilidade do sistema pelo usuário o que torna a experiencia desconfortável as veses até confusa.
